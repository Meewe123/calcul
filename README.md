# calcul

Лёгкий калькулятор в одном файле `index.html` — без зависимостей и сборки.

## Запуск

Откройте `index.html` в браузере.

## Возможности

- Сложение, вычитание, умножение, деление
- `%`, смена знака `±`, сброс `C`
- Деление на ноль показывает «Ошибка»
- Управление с клавиатуры: цифры, `+ - * /`, `.` или `,`, `Enter`/`=`, `Backspace`, `Esc`
